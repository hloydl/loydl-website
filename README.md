## 📋 Overview

Corporate website showcasing three service areas:
1. **IT Consulting & Training** - Business Analysis, Domain Modelling, IT Architecture
2. **Business Process Automation** - Camunda BPM, Workflow Automation
3. **AI Communication Solutions** - fluxdeck.io KI-Telefonie Platform

---

## 🚀 Tech Stack

- **Frontend:** Plain HTML5, TailwindCSS (via CDN)
- **JavaScript:** Vanilla JS (no framework)
- **Deployment:** Netlify / Cloudflare Pages
- **Forms:** Formspree (contact form)
- **Hosting:** Static site hosting (no backend required)

**Why this stack?**
- ⚡ **Fast:** Zero build time, instant deployment
- 🎨 **Modern:** TailwindCSS for responsive design
- 💰 **Free:** Hosting on Netlify/Cloudflare (no cost)
- 🔧 **Simple:** No npm, webpack, or complex tooling
- 📱 **Mobile-first:** Responsive out of the box

## 🛠️ Development

### Local Development

```bash
# Clone repo
git clone https://github.com/loydl/loydl-website.git
cd loydl-website

# Open in browser (no build step!)
open index.html

# Or use Python simple server
python3 -m http.server 8000
# Visit: http://localhost:8000
```

### Deploy to Netlify

**Option 1: Netlify UI**
1. Push code to GitHub
2. Go to https://app.netlify.com
3. Click "New site from Git"
4. Connect GitHub repo `loydl/loydl-website`
5. Build settings: **Leave empty** (static HTML!)
6. Deploy!

**Option 2: Netlify CLI**
```bash
# Install Netlify CLI
npm install -g netlify-cli

# Deploy
netlify deploy --prod
```

**Custom Domain Setup:**
1. Netlify Dashboard → Domain Settings
2. Add custom domain: `loydl.ch`
3. Update DNS at your registrar:
   ```
   A Record: loydl.ch → Netlify IP
   CNAME: www → <your-netlify-domain>.netlify.app
   ```
4. SSL certificate auto-generated by Netlify

## 📝 Content Updates

### Update Contact Form

Replace Formspree Form ID in `contact.html`:
```html
<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
```

Get your Form ID:
1. Sign up at https://formspree.io
2. Create new form
3. Copy form ID
4. Replace `YOUR_FORM_ID` in contact.html

### Add Images

```bash
# Add logo
cp your-logo.png assets/images/logo.png

# Update references in HTML
# Example: <img src="assets/images/logo.png" alt="LOYDL Logo">
```

### Update LinkedIn/Social Links

Find and replace in all HTML files:
```html
<!-- Current placeholder -->
<a href="https://www.linkedin.com/in/harald-loydl">

<!-- Replace with your actual LinkedIn URL -->
```
