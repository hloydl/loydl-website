## 📋 Overview

Corporate website showcasing three service areas:
1. **IT Consulting & Training** - Business Analysis, Domain Modelling, IT Architecture
2. **Business Process Automation** - Camunda BPM, Workflow Automation
3. **AI Communication Solutions** - fluxdeck.io KI-Telefonie Platform

---

## 🚀 Tech Stack

- **Frontend:** Plain HTML5, TailwindCSS (via CDN)
- **JavaScript:** Vanilla JS (no framework)
- **Deployment:** Vercel (same as fluxdeck.io)
- **Forms:** Formspree (contact form)
- **Hosting:** Static site hosting (no backend required)

**Why this stack?**
- ⚡ **Fast:** Zero build time, instant deployment
- 🎨 **Modern:** TailwindCSS for responsive design
- 💰 **Free:** Hosting on Vercel (no cost)
- 🔧 **Simple:** No npm, webpack, or complex tooling
- 📱 **Mobile-first:** Responsive out of the box
- 🔄 **Consistent:** Same platform as fluxdeck.io

## 🛠️ Development

### Local Development

```bash
# Clone repo
git clone https://github.com/hloydl/loydl-website.git
cd loydl-website

# Open in browser (no build step!)
open index.html

# Or use Python simple server
python3 -m http.server 8000
# Visit: http://localhost:8000
```

### Deploy to Vercel

**Option 1: Vercel UI (Recommended)**
1. Push code to GitHub
2. Go to https://vercel.com/new
3. Click "Import Git Repository"
4. Select `hloydl/loydl-website`
5. Build settings:
   - Framework Preset: **Other**
   - Build Command: (leave empty)
   - Output Directory: `.` or (leave empty)
6. Deploy!

**Option 2: Vercel CLI (Faster)**
```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
cd /path/to/loydl-website
vercel --prod

# Follow prompts:
# - Set up and deploy? Yes
# - Which scope? hloydl
# - Link to existing project? No
# - Project name? loydl-website
# - Directory? ./ (Enter)
# - Override settings? No
```

**Custom Domain Setup:**
1. Vercel Dashboard → Project Settings → Domains
2. Add custom domain: `loydl.ch`
3. Update DNS at your registrar:
   ```
   A Record: loydl.ch → 76.76.21.21 (Vercel)
   CNAME: www → cname.vercel-dns.com
   ```
4. SSL certificate auto-generated by Vercel (Let's Encrypt)

**Why Vercel?**
- Same platform as fluxdeck.io (consistency!)
- Faster deployments & better Edge Network
- Excellent Git integration with preview deployments
- Better analytics in free tier

## 📝 Content Updates

### Update Contact Form

Replace Formspree Form ID in `contact.html`:
```html
<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
```

Get your Form ID:
1. Sign up at https://formspree.io
2. Create new form
3. Copy form ID
4. Replace `YOUR_FORM_ID` in contact.html

### Add Images

```bash
# Add logo
cp your-logo.png assets/images/logo.png

# Update references in HTML
# Example: <img src="assets/images/logo.png" alt="LOYDL Logo">
```

### Update LinkedIn/Social Links

Find and replace in all HTML files:
```html
<!-- Current placeholder -->
<a href="https://www.linkedin.com/in/harald-loydl">

<!-- Replace with your actual LinkedIn URL -->
```
